# Plumo

Un petit oiseau à faire voler entre les colonnes : un battement à chaque clic. Le ciel change avec ton score, des médailles à gagner.

Clic, espace ou flèche du haut : un battement d'ailes. Les colonnes se resserrent petit à petit. Médailles : bronze à 10, argent à 25, or à 50, platine à 100.

Ses données (records, réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Plumo → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
